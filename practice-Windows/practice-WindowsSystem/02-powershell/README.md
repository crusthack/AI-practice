# 02. PowerShell

목표:

- PowerShell이 문자열이 아니라 객체를 파이프라인으로 넘긴다는 점을 이해합니다.
- `Get-Help`, `Get-Command`, `Get-Member`를 습관화합니다.
- 간단한 스크립트와 함수로 반복 작업을 자동화합니다.

핵심 명령:

```powershell
Get-Command
Get-Help
Get-Member
Get-ChildItem
Where-Object
Select-Object
Sort-Object
Export-Csv
ConvertTo-Json
```
